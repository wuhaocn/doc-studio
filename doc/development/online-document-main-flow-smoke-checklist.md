# 在线文档系统主流程冒烟验收清单

## 1. 目的

本文档用于固定当前在线文档系统最核心的人工验收路径，避免每次只靠口头描述“应该能用”。

当前聚焦的验收主链路是：

`admin 登录 -> 工作台 -> 切换工作区 -> 统一搜索 -> 创建知识库 -> 创建文档 -> 编辑保存 -> 查看版本 -> 删除恢复 -> 查看审计 -> 创建受控分享 -> API key 写入文档 -> 退出登录`

---

## 2. 验收前提

### 2.1 后端

启动命令：

```bash
./start-backend.sh
```

当前已知状态：

- 后端主链路的最小集成测试已具备
- `start-backend.sh` 默认会通过共享脚本优先使用 `./gradlew`
- 使用 wrapper 时会在仓库内设置 `GRADLE_USER_HOME`，避免写入用户主目录
- 如果本地既没有可用的系统 Gradle，也没有已缓存的 wrapper 分发包，后端启动仍会受本机 Gradle 环境限制
- 关键测试文件：
  - [OnlineDocumentApiIntegrationTest.java](../../memora-server/memora-server-start/src/test/java/com/memora/OnlineDocumentApiIntegrationTest.java)


当前已知状态：

- `npm run lint` 已通过
- `npm run test:unit` 已通过
- `npm run build` 已通过

## 4. 人工冒烟步骤

### 4.1 登录

步骤：

1. 打开 `/login`
2. 输入 `admin / 123456`
3. 点击登录动作

期望结果：

- 成功进入工作台 `/`
- 顶部导航可见，且可以退出当前会话
- 未登录访问受保护页面时会被重定向到登录页

### 4.2 工作台查看

步骤：

1. 进入工作台首页
2. 查看最近文档、最近编辑项、知识库列表

期望结果：

- 工作台加载成功
- 第一屏优先展示最近编辑文档入口
- 能看到当前租户的知识库列表
- `admin` 可以点击“新建知识库”

### 4.3 多工作区切换

步骤：

1. 使用 `admin / 123456` 登录
2. 在顶部工作区切换器中选择另一个已加入工作区
3. 等待页面刷新并重新进入工作台

期望结果：

- 顶部工作区名称切换为新租户
- 工作台内容切换为新工作区的数据
- 最近访问知识库上下文被清理，不会把旧工作区知识库带入新工作区

### 4.4 工作区统一搜索

步骤：

1. 在顶部搜索框输入关键词
2. 进入 `/search`
3. 查看按知识库分组的命中结果

期望结果：

- 结果只覆盖当前工作区
- 结果按知识库分组展示
- 结果只返回正文文档，不混入目录节点
- 只读角色只看到阅读入口，可写角色额外看到编辑入口

### 4.5 创建知识库

步骤：

1. 在工作台点击新建知识库
2. 输入名称和描述
3. 提交表单

期望结果：

- 自动跳转到新知识库详情页
- 侧边栏知识库导航自动刷新
- 顶部在线文档入口不再硬编码 `/kb/1`，而是进入当前或最近知识库

### 4.6 创建文档

步骤：

1. 在知识库详情页点击新建文档
2. 只输入标题
3. 提交创建

期望结果：

- 新节点出现在文档树中
- 新文档自动选中
- 如果是文档节点，自动进入独立编辑页
- 摘要和父级目录不是创建前置条件

### 4.7 编辑保存

步骤：

1. 打开独立编辑页
2. 在富文本编辑器中修改正文
3. 点击保存并生成版本

期望结果：

- 出现保存成功提示
- 首屏主要区域聚焦正文编辑
- 页面不再把知识库级信息和侧栏导航作为主焦点
- 文档版本号递增
- 返回知识库后，摘要和正文预览刷新

### 4.8 查看版本

步骤：

1. 在独立编辑页点击查看版本
2. 选择一个历史版本进行对比

期望结果：

- 能看到新生成的版本记录
- 版本按时间倒序展示
- 当前版本与历史版本差异可见
- 编辑页可直接切换到阅读页，不需要先回知识库

### 4.9 删除与恢复

步骤：

1. 在知识库详情页删除当前文档或目录
2. 打开“文档回收站”并恢复刚删除的内容
3. 删除当前知识库
4. 回到工作台打开“知识库回收站”并恢复刚删除的知识库

期望结果：

- 删除后的文档不会继续出现在当前树中
- 文档回收站可列出刚删除的文档或目录
- 恢复文档后重新回到当前知识库树
- 删除后的知识库不会继续出现在工作台知识库列表中
- 知识库回收站可列出刚删除的知识库
- 恢复知识库后重新出现在工作台列表中

### 4.10 复制阅读链接

步骤：

1. 在知识库正文区或独立编辑页点击复制阅读链接
2. 执行复制
3. 在已登录且具备权限的会话中打开链接

期望结果：

- 可复制独立文档阅读链接
- 复制阅读链接不需要先进入编辑模式
- 打开的目标是当前文档阅读页，不是知识库首页
- 接收方不需要先进入知识库再手动找文档
- 链接本身不会放宽权限，未登录或无权访问的用户仍会被拒绝

### 4.11 查看审计

步骤：

1. 使用 `admin / 123456` 登录
2. 在首页确认“最近审计记录”可见
3. 创建或编辑一个知识库文档后，返回首页或知识库详情页查看最近记录

期望结果：

- 工作区管理员可以看到最近关键操作
- 知识库上下文面板可以看到知识库和当前节点最近记录
- 审计记录应包含动作、操作者、来源和时间
- `viewer` 不应看到工作区级审计入口，也不能通过接口查询成功

### 4.12 退出登录

步骤：

1. 点击顶部退出动作

期望结果：

- 返回登录页或使受保护页面失效
- 本地会话数据被清除
- 最近访问知识库记录被清除

## 5. 当前重点回归项

人工验收时重点确认以下风险没有回归：

- 登录后知识库导航是否仍有硬编码跳转
- 工作区切换后是否仍错误保留旧工作区知识库上下文
- 统一搜索是否混入目录节点或越过知识库权限边界
- 创建知识库后是否还需要回列表再手动进入详情
- 创建文档后是否还需要额外点一次编辑器
- 保存正文后版本列表是否刷新
- 删除后的知识库和文档能否从回收站恢复
- 首页和知识库上下文的最近审计记录是否按权限显示并及时刷新
- 受限角色是否正确禁用按钮并拒绝未授权操作

## 6. 当前结论

截至当前代码状态：

- 后端主链路已有自动化回归保障
- Web 端主链路具备人工冒烟基础

- 完整权限产品化、高级协作编辑仍未完成
